# ERP Nexus - Frontend Technical Test API

Dockerized backend built with **FastAPI + Swagger (OpenAPI 3)** mirroring the project's `snake_case` contracts and `{ code, message, result }` / `{ code, message, details }` response structure.

## Run with Docker

```bash
docker compose up --build
```

## Endpoints

- **Swagger UI:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc
- **OpenAPI JSON:** http://localhost:8000/openapi.json
